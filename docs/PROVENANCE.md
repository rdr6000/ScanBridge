# Provenance

- All ScanBridge source code was written independently for this project between 2026-10-29 and 2026-10-30.
- No source files, snippets, assets, logos, product text, screen layouts or protocol from Barcode to PC (GPL-3.0) were copied, ported or translated.
- The upstream repositories and website were used **only** to list user-visible features. That audit is in `REFERENCE_AUDIT.md`, and its sources are in `REFERENCE_SOURCES.md`.

| Module | Origin |
|---|---|
| `packages/scanbridge_domain` | Original |
| `packages/scanbridge_protocol` | Original protocol design (see `PROTOCOL.md`). Not wire-compatible with Barcode to PC |
| `packages/scanbridge_template_engine` | Original component model, JSON schema and execution engine |
| `packages/scanbridge_storage` | Original Drift schema |
| `packages/scanbridge_ui` | Original design system. The English and Hindi strings were written for this project |
| `apps/desktop` | Original. The Windows input adapter uses the documented Win32 `SendInput` API through the `win32` package |
| `apps/mobile` | Original. Camera decoding uses `mobile_scanner` |
| Platform runners (`windows/`, `android/`, `ios/`, …) | Generated by `flutter create` (BSD-3 Flutter templates) with small edits |

Third-party code comes only through the pub dependencies listed in `DEPENDENCY_LICENSES.md`. Any future proposal to reuse upstream code needs a separate license review first.
